# 🏥 Hospital Emergency Room Analytics Dashboard - Excel

An interactive **Microsoft Excel Dashboard** designed to analyze Emergency Room (ER) operations, patient demographics, department referrals, waiting times, admissions, and service quality metrics.

The dashboard transforms raw hospital admission records into an interactive reporting interface that helps identify operational trends, patient-flow patterns, and potential service bottlenecks.

---

## 📊 Dashboard Overview

The dashboard provides a consolidated view of ER performance through interactive **KPIs, charts, PivotTables, slicers, and timelines**.

### Key KPIs

* **Total Patients** — Total number of ER visits within the selected period.
* **Average Wait Time** — Average time, in minutes, between patient arrival and initial consultation.
* **Patient Satisfaction Score** — Average patient feedback score out of 5.
* **Admission Rate** — Percentage of ER patients admitted for inpatient care.
* **On-Time vs. Delayed Performance** — Service performance against defined response-time benchmarks.
* **Department Referral Volume** — Number of patients referred to each clinical department.

### Patient Demographics

* Age-group distribution from **0–12 through 85+**
* Gender distribution
* Patient volume across selected time periods

## 🔄 Data Preparation

The raw hospital records were cleaned and transformed before being used in the dashboard.

Key preparation steps included:

1. Cleaning and standardizing raw patient records
2. Structuring the dataset into Excel Tables
3. Creating derived fields such as **Age Group**
4. Preparing admission and referral categories
5. Building PivotTables for analytical summaries
6. Connecting dashboard visuals to interactive filters

## 🎯 Business Questions Addressed

The dashboard can help answer questions such as:

* How many patients visited the ER during a selected period?
* What is the average patient waiting time?
* What proportion of patients were admitted?
* Which departments receive the highest number of referrals?
* How are ER visits distributed across age groups and genders?
* How does patient satisfaction change over time?
* What is the proportion of on-time versus delayed service?

## 🚀 How to Use

1. Download `Hospital Dashboard.xlsx`.
2. Open the workbook in **Microsoft Excel**.
3. Navigate to the dashboard sheet.
4. Use the **year/month filters, slicers, and timeline controls** to explore different periods.
5. Review the KPI cards and charts to analyze ER performance.

---

## ⚠️ Data Note

All patient records in this project are fully anonymized and synthetic, created strictly for analytical and demonstration purposes. No real patient health information (PHI) is contained in this dataset.

---

## 📌 Project Objective

The primary objective of this project is to demonstrate how **Excel-based data analysis and visualization** can transform raw healthcare operational data into an interactive dashboard for monitoring ER performance and patient-flow metrics
